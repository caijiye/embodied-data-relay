# 外壳（参考设计）

`tray.scad` 是一个参数化 OpenSCAD 托盘，用于：

- 2 × 3.5" HDD（101.6 × 147 × 26.1 mm）
- 1 台 130 × 130 mm 小主机
- 1 × 120 mm 风扇
- 线缆过孔与底部通风槽

## 状态

**Reference only**：尚未打印/实测。不同小主机与硬盘的孔位不同，请先测量再调整参数。

## 打印建议

- 材料：PETG（耐温、韧性好）或 ASA（户外/高温）；PLA 不适合长期 40°C+ 环境。
- 层高：0.2 mm；壁厚：4 圈；填充：20-30%。
- 支撑：HDD 立筋与风扇框可能需要支撑；优先重新定向减少支撑。
- 公差：孔位留 0.3-0.5 mm；M3 螺丝孔按 3.4 mm 打印。
- 减震：HDD 与托盘之间加 2 mm 橡胶垫；风扇加橡胶柱。

## 装配

1. 打印托盘与风扇框。
2. 安装 HDD 减震垫与侧轨。
3. 固定小主机铜柱。
4. 安装风扇（进风侧加防尘网）。
5. 理线，确保 HDD 之间 ≥10 mm 风道。
6. 上电测试温度与振动；必要时降低风扇转速。

## 文件

- `tray.scad`：参数化源文件（CERN-OHL-S-2.0）。
- 导出 STL：在 OpenSCAD 中打开 → F6 → File → Export as STL。
- 如需 STEP：OpenSCAD 导出 CSG/STL 后用 FreeCAD 转换。

## 替代方案

没有 3D 打印机时：

- 用亚克力板 + 铜柱做两层开放框架；
- 用现成 ITX 机箱 + 3.5" 硬盘架；
- 用 EVA 泡棉 + 扎带做临时减震（仅演示，不长期运行）。

无论哪种方案，保持风道、减震与接地。
