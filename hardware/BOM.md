# 硬件 BOM（MVP，预算 < 5000 元）

目标：用现有 x86 小主机 + 一块 NVMe + 一块 HDD，搭出可演示的「具身数据驿」单机。

| 项 | 规格 | 数量 | 参考价（元） | 备注 |
|---|---|---:|---:|---|
| x86 小主机 | 现有，N100/i5 级别，至少 1 个 M.2 NVMe + 1 个 SATA/USB3 | 1 | 0 | 已有 |
| NVMe SSD | 2 TB，TLC，PCIe 3.0/4.0 | 1 | 700 | 写入缓冲/热数据 |
| HDD | 16 TB，CMR，SATA | 1 | 2500 | 已有可省；冷数据 |
| HDD 连接 | SATA 线/电源，或 USB 3.0 硬盘盒 | 1 | 100 | 小主机无 SATA 时用 USB3 |
| UPS | 600 VA 后备式 | 1 | 300 | 掉电保护 |
| 健康监控 | ESP32-S3 + 0.96" OLED + INA226 + DHT22 + 5V PWM 风扇 | 1 | 150 | 可选，开源固件 |
| 外壳 | 亚克力/3D 打印 + 铜柱/螺丝 | 1 | 300 | 开源 STEP/图纸 |
| 线材/散热 | SATA 电源、风扇、导热垫 | 1 | 100 | |
| **合计** | | | **约 4150** | 不含已有主机/硬盘 |

## 采购优先级

1. NVMe（必须有；没有它就没有「热层」）
2. UPS（必须有；掉电保护是数据采集现场的刚需）
3. HDD（已有则跳过）
4. ESP32 健康监控（加分项，不影响主线）
5. 外壳（路演观感，最后做）

## 兼容性检查

- 小主机是否有空闲 M.2 NVMe 插槽？协议是 NVMe 还是 SATA M.2？
- 是否有 2.5" SATA 位？没有就用 USB 3.0 硬盘盒（注意 UASP 支持）。
- 网口是 1GbE 还是 2.5GbE？1GbE 下单路压缩视频够用；8 路 raw 需 10GbE 或本地直录。
- 电源功率是否够两块盘 + 小主机？N100 主机通常 65W 电源够；加 HDD 建议 90W 以上。
- 是否有 3D 打印机/亚克力加工资源？没有就用现成机箱 + 开源图纸。
