# 接线与装配

> 安全边界：本项目不涉及市电改装。使用通过认证的 UPS；12V/5V 直流侧加保险丝；所有金属外壳接地。没有电气经验时请使用现成硬盘盒与成品电源。

## 拓扑

```
         ┌──────────────┐
         │   UPS 600VA  │
         └──────┬───────┘
                │ AC
     ┌──────────┴───────────┐
     │  x86 小主机           │
     │  ├─ M.2 NVMe (hot)    │
     │  ├─ SATA/USB3 HDD     │
     │  └─ USB → ESP32-S3    │
     └──────────┬───────────┘
                │ 1GbE/2.5GbE
         ┌──────┴──────┐
         │  训练集群/云 │
         └─────────────┘
```

ESP32 只做健康监控，不参与数据路径；即使 ESP32 掉线，数据管线仍可运行。

## ESP32-S3 接线

| ESP32-S3 | 连接 | 说明 |
|---|---|---|
| 5V / GND | USB 5V（来自小主机或 UPS） | 不要从 12V 直接降压到 3.3V；用 USB 供电 |
| GPIO5 | 4-pin PWM 风扇 PWM | 25 kHz，3.3V PWM；共地 |
| GPIO4 | 风扇 TACH | 内部上拉；部分风扇需要 10k 上拉到 3.3V |
| GPIO1 | NTC 分压中点 | NTC 10k 接 3.3V，10k 电阻接 GND |
| GPIO8/9 | OLED I2C（可选） | SDA/SCL；固件默认不启用 OLED |
| GPIO2/3 | INA226 I2C（可选） | 用于电流/功率；需要 0.1Ω 分流电阻 |

风扇 4-pin 定义（常见）：

1. GND（黑）
2. +12V（黄）
3. TACH（绿）
4. PWM（蓝）

ESP32 只接 GND、TACH、PWM；**不要**把 12V 接到 ESP32。

## 硬盘

- 优先 SATA 直连；小主机没有 SATA 时用 USB 3.0 硬盘盒（确认 UASP）。
- HDD 单独供电时，共地；避免热插拔（除非使用支持热插拔的背板）。
- 2 块 HDD 之间留 ≥10 mm 间距；加 120 mm 风扇低速吹。

## UPS

- 600 VA 后备式即可；接小主机 + HDD。
- 目标：断电后至少 2 分钟，足够完成当前写入并安全关机。
- 定期做一次断电演练，记录恢复结果。

## 装配顺序

1. 固定 HDD 与减震垫。
2. 固定小主机，接 NVMe。
3. 接 SATA/USB 与电源。
4. 接 ESP32（USB 供电、风扇、NTC）。
5. 理线，确保风扇进风不被遮挡。
6. 上电，先跑 `edr scan`，再跑 `edr pipeline`。
7. 检查 dashboard 的 telemetry 与磁盘温度。

## 参考尺寸

- 托盘：340 × 330 mm（见 `enclosure/tray.scad`）。
- 2× 3.5" HDD：101.6 × 147 × 26.1 mm。
- 120 mm 风扇：120 × 120 × 25 mm。
- 小主机：按实际型号测量；托架留 5 mm 公差。
