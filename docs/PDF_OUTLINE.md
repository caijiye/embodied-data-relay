## 3. 问题

- 具身数据规模：70+ 训练场、百万小时需求、AgiBot World Alpha 9.66 TB、8 路 1080p 未压缩 ~1.5 GB/s。
- 交付瓶颈：1 TB / 100 Mbps ≈ 22 h；10 Mbps ≈ 9 天。
- 可用率：行业口径约三成素材能进训练。
- 现有方案不足：NAS + bcache/dm-cache 不感知会话；云存储贵且慢；数据采集公司多卖传感器/服务，不做边缘数据站。

## 4. 方案

- 会话感知写入：NVMe 追加缓冲区 + 掉电保护；封存后再分层。
- 边缘质量门禁：模糊/曝光/重复/黑帧；隔离不删除。
- 编码减量：H.264 + Parquet/MCAP+ZSTD；训练就绪包。
- 热冷分层：NVMe 热、HDD 冷、元数据常驻；按 episode 随机读。
- 交付调度：优先级、重试、断点；可选数据胶囊。

## 5. 硬件设计

- 小主机 + 2 TB NVMe + 16 TB HDD + UPS + ESP32 健康监控。
- 开源 BOM、接线、OpenSCAD 外壳、固件。
- 成本目标 < 5000 元（不含已有主机/硬盘）。
- 可复现性：别人照着 BOM/图纸能装出来。

## 6. 与现有方案的差异

| 方案 | 会话感知 | 质量门禁 | 边缘减量 | 交付调度 | 开源硬件 |
|---|---|---|---|---|---|
| NAS + SSD cache | 否 | 否 | 否 | 弱 | 部分 |
| bcache/dm-cache | 否 | 否 | 否 | 否 | 否 |
| 云对象存储 | 否 | 否 | 否 | 弱 | 否 |
| 具身数据驿 | 是 | 是 | 是 | 是 | 是 |

## 7. Benchmark

- 数据：2 sessions / 14 episodes / 2 cameras / 153.3 MB；注入缺陷。
- 10 Mbps：123.9 s → 9.2 s，13.53×；100 Mbps 下处理时间占主导，加速比收敛到约 1.5×。
- 质量门禁剔除 29.4%；编码减量 99.3%（合成上界）；总减量 99.5%。
- 说明合成数据局限；真实数据 pilot 计划。
