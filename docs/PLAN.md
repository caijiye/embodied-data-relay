# 11 天冲刺计划（2026-10-20 → 2026-10-31）

## 目标

在 2026-10-31 24:00 前提交一套可运行、可复现、可演示的赛道二作品：

1. 公开代码仓库（完整可运行）
2. 作品介绍 PDF（背景、架构、场景、创新点）
3. 3-5 分钟演示视频

## MVP 范围（必须完成）

- 单机边缘节点，不做集群。
- 输入：目录式采集会话（多相机图像序列/视频 + 状态 JSONL + meta.json）。
- 会话发现与完整性判断。
- 质量门禁：模糊、过暗/过曝、重复帧、黑帧；隔离但不删除。
- 压缩：图像序列/视频 → H.264 MP4；状态保留 JSONL/Parquet。
- 分层：NVMe hot → HDD cold；SQLite 元数据索引。
- 交付：MinIO/S3 上传，重试与断点记录，交付延迟统计。
- 仪表盘：吞吐、减量比、质量分布、分层、交付队列。
- Benchmark：纯 HDD 基线 vs 具身数据驿管线。
- 开源治理：LICENSE、README、ARCHITECTURE、BENCHMARKS、ROADMAP、CONTRIBUTING、SECURITY、BOM、接线、外壳。

## 非目标（11 天内不做）

- 多机集群调度。
- 自定义 PCB 量产级设计（用现成模块 + 开源接线图；KiCad 作为 stretch goal）。
- 完整 LeRobot v3 规范导出（先做训练就绪的 Parquet + MP4 + manifest；如时间允许再加 exporter）。
- 10GbE / 数据胶囊硬件（写入路线图）。
- 自动标注 / VLM 任务成功判定（先用轻量图像质量指标）。

## 关键风险

1. **参赛主体**：报名表无个人选项，必须企业/高校/科研机构/开源社区/学生团队/联合申报。今天联系 `bjoscc@oschina.cn`。
2. **硬件到货**：NVMe/HDD/UPS 到货是 critical path；先用现有机器跑软件，硬件到了再整机。
3. **单人开发**：范围必须砍到单机 MVP；仪表盘用服务端渲染，不做重型前端。
4. **数据真实性**：用公开具身数据集样本 + 合成多相机录制；benchmark 注明合成/真实比例。
5. **视频制作**：10-29 必须开录，不能等到最后一天。
